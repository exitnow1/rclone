Privacy Policy

Last updated: September 26, 2026

Overview

This application is a personal-use application created solely for use by its owner with rclone and Google Drive.

The application is used to authorize rclone to access the owner's Google Drive accounts for file management, transfer, backup, and synchronization purposes.

Google User Data Access

The application may access Google Drive files, folders, and associated metadata as necessary to perform file operations requested by the application owner.

Depending on the operation performed with rclone, this access may include listing, reading, copying, creating, modifying, uploading, downloading, or deleting files and folders in Google Drive.

Purpose of Data Access

Google user data is accessed solely for personal file management, backup, synchronization, and transfer operations initiated by the application owner through rclone.

Data Processing

This application does not operate a separate public web service or application server that collects Google Drive file contents. File operations are performed through rclone running on the application owner's own computer and through Google's APIs.

Authentication Data

OAuth authorization information required by rclone, such as access tokens and refresh tokens, may be stored locally on the application owner's computer as part of the rclone configuration.

This information is used only to authenticate requests made by rclone to Google APIs.

Data Sharing

Google user data obtained through this application is not sold, rented, or shared with third parties for advertising, marketing, analytics, or other unrelated purposes.

Data may be transmitted between the application owner's computer and Google services as necessary to perform the requested rclone operations.

Data Storage

The application does not maintain an independent remote database containing Google Drive user data.

Files copied or downloaded using rclone may be stored at destinations explicitly selected by the application owner, such as local storage or another authorized Google Drive account.

Data Retention and Deletion

Files and other data are retained only at locations selected and controlled by the application owner.

The application owner may delete transferred files, local rclone configuration data, or revoke the application's Google Account access at any time.

Limited Use

Google user data accessed through this application is used only for providing the file management, transfer, backup, and synchronization functionality requested by the application owner.

Application Availability

This application is intended solely for personal use by its owner and is not offered as a public service to other users.

Contact

For questions regarding this privacy policy, please contact the application developer.
